# 📱 Task Manager - CRUD con Room
Una aplicación Android para gestionar tareas, desarrollada con Java y Room Database. Permite crear, leer, actualizar y eliminar tareas de manera eficiente.

## 🚀 Características
- ✅  Crear nuevas tareas
- 👀  Ver lista de tareas
- ✏️  Editar tareas existentes
- 🗑️  Eliminar tareas
- 🎨  Interfaz moderna con Material Design

##Cómo Usar la Aplicación

### 1.Ver Lista de Tareas
- Al abrir la app, verás todas las tareas guardadas
- Las tareas se muestran en orden de creación (más recientes primero)
- Cada tarea muestra: título, descripción, fecha y estado

### 2.Crear Nueva Tarea
1. Toca el botón  flotante en la esquina inferior derecha
2. Completa el formulario:
    - Título (obligatorio)
    - Descripción (opcional)
    - Estado (marcar si está completada)
3. Toca "Guardar" para crear la tarea

### 3.Editar Tarea Existente
1. En la lista, toca el botón "Editar" (verde) en la tarea deseada
2. El formulario se abrirá con los datos actuales
3. Modifica los campos necesarios
4. Toca "Actualizar" para guardar cambios o "Cancelar" para descartar

### 4.Eliminar Tarea
1. En la lista, toca el botón "Eliminar" (rojo) en la tarea deseada
2. La tarea se eliminará inmediatamente
3. Aparecerá un mensaje de confirmación
